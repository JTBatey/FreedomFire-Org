# Open-source font candidates — review only

Figtree and Jost were selected and moved with their licenses to `../../assets/fonts/`.
The main website now uses them. This folder keeps only Albert Sans and
Montserrat for reference in `../font-comparison.html`.

Downloaded September 18, 2026 from the official Google Fonts repository:

| Local file | Original source |
| --- | --- |
| Figtree-Variable.ttf | https://github.com/google/fonts/tree/main/ofl/figtree |
| AlbertSans-Variable.ttf | https://github.com/google/fonts/tree/main/ofl/albertsans |
| Montserrat-Variable.ttf | https://github.com/google/fonts/tree/main/ofl/montserrat |
| Jost-Variable.ttf | https://github.com/google/fonts/tree/main/ofl/jost |

Each font's full SIL Open Font License 1.1 and copyright notice is included in
its corresponding `*-LICENSE.txt`. Keep these notices with any redistributed
font files. These licenses permit embedding and redistribution under their
conditions; no font-service account is needed for this local hosting setup.

Approved choice: Figtree for Proxima Nova, Jost for Futura PT.
Albert Sans and Montserrat remain alternatives in the comparison controls.
This is a visual judgment, not a claim of identical metrics or letterforms.
At desktop comparison width, some replacement paragraphs wrap differently.

Adobe requests have been removed, including from the comparison page. Keep
the chosen fonts' licenses beside them in `assets/fonts/` when publishing.
